# Spicy AMLL renderer port

The renderer modules in this directory are adapted from Spicy AMLL Player WEB by the Spicy AMLL contributors, based on the upstream nypdv1/spicy-amll-player project.

- Upstream: https://github.com/nypdv1/spicy-amll-player
- Fork used for this port: https://github.com/Melodii7785/spicy-amll
- License: GNU Affero General Public License v3.0 (AGPL-3.0-only)

The port is experimental and scoped to Lyric Thing's /testingthisisexperimental/ route. The host app's lyric providers, Spotify integration, and production AMLL renderer remain separate.
